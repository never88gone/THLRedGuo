# 糖葫芦Haw Apple TV 更新日志

## 1.0.0 (2026-11-08)
- 根除视频起播后准备流浮层残留遮挡问题：播放状态就绪及进度推进时底层强制复位 isLoading，并在视图层增加实际播放守卫，杜绝视频播放中误显示“正在准备视频流”浮层
- 建立长程 5 分钟连续播放端到端 UI 自动化测试基线，在模拟器上完整验证了连播 300 秒、跨越 4 集自动连播、每集起播与推进正常、无卡死无浮层遮挡的稳定性闭环
- 修复一集播完自动切入下一集卡住问题：在复用现有播放器进行切集时，为零进度起播显式增加播放头归零重置（seek to zero），杜绝残留上一集末尾时间戳导致系统判定播放已结束而无法起播
- 完善底层播放器容器分集同步机制：为 AVPlayerContainerView 增加 currentItem 观察者，切集时自动重新挂载新 item 状态与播放结束监听，保持渲染图层与播放器生命周期一致
- 为连续播放无缝过渡增加 1.5 秒超时保底，防止由于网络请求或解析偶发延迟导致界面定格假死，并通过端到端 UI 自动化测试验证了自然播完连续过渡与平稳推进
- 修复播放器暂停不生效问题：将播放意图精确透传到底层 AVPlayerView 容器，彻底消除界面刷新误唤醒播放
- 修复画中画会话状态遗留导致的退出播放再进入黑屏问题：增加画中画活跃状态强守卫并在退出时主动注销，杜绝误走画中画恢复分支
- 根治推荐页卡顿与视频流准备卡死问题：为 JavaScriptCore 异步评估引入专用工作队列信号量串行隔离机制，杜绝多任务并发重入导致的虚拟机底层锁死与 CPU 占满
- 优化推荐流后台预热管线：收拢后台预热并发度为单部顺序解析，当前视频起播前留出独占缓冲窗口，取消后台额外创建静音 AVPlayer，消除硬件解码器会话争抢
- 提升侧边栏焦点掠过推荐页防抖时长至 400ms，杜绝遥控器快速滑动时的非预期误触发起播
- 侧边栏导航条目高度调矮至适中轻盈的 58pt，视觉比例更紧凑优雅
- 优化发现页、榜单、搜索结果及我的页面卡片获焦样式：获焦高亮边框完整包裹海报与文字标题及更新进度，衬底半透明阴影浑然一体

## 1.0.0 (2026-11-07)
- 修复 Apple TV 真机启动闪退问题：将首页目录缓存彻底迁移至沙盒 Cache 文件存储，并在启动时主动清理历史残留在 NSUserDefaults 中的大体积数据，消除 CFPreferences 体积超限导致的 SIGABRT 异常
- 修复推荐页面（Feed）准备视频流时 UI 卡死问题：消除前后台对当前推荐短剧的重复解析与资源争抢，将后台预热改造为只针对后续剧集
- 彻底解除 TVTouchCapturingView 对 tvOS 系统 Responder 链与 Menu/按键事件的拦截与吞噬，恢复物理遥控器随时切集与退出能力
- 优化播放器初始化超时与多季搜索逻辑，短视频流推荐模式下跳过全网多季跨源搜索，后台预热改用 preroll 避免硬件解码器争抢
- 优化发现页面与详情起播链路，消除死锁卡死根因，支持毫秒级平滑秒开
- 将 JS 异步引擎调度改造为非阻塞 Swift Concurrency 协同机制，杜绝信号量阻塞与主线程卡顿冻结
- 优化播放器初始化逻辑，已有分集时跳过冗余全量解析，关联季搜索降级为后台低优先级执行
- 优化侧边栏快速掠过联动机制与高频计时器，解绑播放图层解码器，杜绝页面切换掉帧与卡死
- 新增系统级画中画（PiP）独立小窗播放功能，支持脱离主界面后持续悬浮播放
- 支持画中画小窗模式下自动连续播放下一集，观影进度与本地历史无缝同步
- 支持画中画小窗恢复全屏时精准返回之前的播放器与剧集页面，无缝接续播放
- 优化播放器控制栏交互，将画中画入口提升至第一层主控制栏并常驻显示，打通遥控器焦点循环导航
- 恢复 tvOS 原生应用北京时间“年月日时分秒”规范构建号注入
